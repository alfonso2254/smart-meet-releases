# Smart Meet — Releases

Instaladores oficiales de la app desktop Smart Meet.

Busca la versión más reciente en [Releases](https://github.com/alfonso2254/smart-meet-releases/releases/latest) y descargá el binario para tu sistema operativo.

| Plataforma | Archivo |
|---|---|
| macOS Apple Silicon | `SmartMeet-<version>-arm64.dmg` |
| macOS Intel | `SmartMeet-<version>-x64.dmg` |
| Windows | `SmartMeet-Setup-<version>.exe` *(próximamente)* |

El auto-updater se alimenta de `latest-mac.yml` y `latest.yml` publicados en cada release.
